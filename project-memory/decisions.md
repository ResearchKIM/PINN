- 2026-10-15: 연구실 Business 계정 사용 환경에서 API 키 대신 Codex의 ChatGPT 로그인으로 자연어 PINN 도우미를 사용하기로 요청. 기본 backend=codex, 기존 API 직접 호출은 명시적인 --backend api에서만 사용. 출처: 현재 대화의 '로그인 방식으로 변경 될까?' 및 앞선 API 키 사용 제약 설명.
- 2026-10-15: 기존 학습 명령이 자연어 변경 값을 바로 읽도록 지정 원본 YAML에 기본 반영한다. 실행별 원본 백업을 남기며 --preview는 미리보기만 수행한다. Python 코드 후보의 원본 자동 반영은 하지 않는다. 출처: 사용자의 기존 --config 명령에 업데이트된 파일을 바로 사용하고 싶다는 요청.
